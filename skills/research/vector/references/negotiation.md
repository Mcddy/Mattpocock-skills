# Negotiation

Used by vector module 7. For Shaun's rate, contract, offer and supplier negotiations.

## Pre-negotiation brief

```
COUNTERPARTY: decision-maker or representative? / stated vs real objectives / their alternative /
              pressures / constraints / style
INTERESTS vs POSITIONS: their stated position / their underlying interest /
                        Shaun's stated position / Shaun's real interest
```

Sources for the counterparty brief are public or freely given.

## Position architecture

```
BATNA:             best alternative if talks fail (the stronger it really is, the stronger the position)
RESERVATION POINT: walk-away threshold, decided before the room, never in it
TARGET POINT:      ambitious but achievable; this is the anchor, not the compromise
ZOPA:              if the ranges do not overlap there is no deal; say so early
```

If the BATNA is weak, the first task is to improve it (another client, another offer), not to bluff about it.

## Five phases

1. Positioning: strengthen the real alternative, establish credibility, shape context before formal talks.
2. Opening: anchor first if the range is unclear; open ambitiously but defensibly; set the agenda.
3. Manoeuvre: concede low-value items for reciprocity; extract high-value ones; trade packages rather than single items.
4. Closing: close explicitly ("If you can do X, we have a deal"); confirm in writing straight away.
5. Exploitation: take the follow-on value: relationship, precedent set, what was learned.

## Honest tactics

- Bracketing: aim for $100, they offer $60, counter at $140 so the midpoint lands at $100. The numbers are real positions, not fictions.
- The trade: never give a concession without asking for one. "I can do X if you can do Y."
- Silence: after any offer, stop talking. The next to speak concedes ground.
- "You'll need to do better than that." Then wait.
- Time to consult: when a real person or process must approve, say so and take the time. This is true delay, not a device.
- Not disclosing the reservation point, deadline pressure or alternatives is concealment and is allowed. Stating them falsely is not.

## Changed or removed for honesty (original tactics, for Shaun to review)

| Original | Change | Why |
|---|---|---|
| The Flinch: visibly recoil at any position before replying | Dropped. Replace with a plain statement: "That is well outside what I had in mind." | A staged reaction is a performance meant to mislead about how Shaun really feels. |
| Higher Authority: "I'd agree but I need to check with X" | Kept only when X is a real approver. Otherwise "I'll take that away and come back to you." | Inventing an approver is a false statement. |
| Phase 1: "signal BATNA strength" | Kept for a real alternative only | Implying alternatives that do not exist is false. |
| Anchor ambitiously | Kept, but the anchor must be defensible with a true rationale | An absurd anchor with invented justification is misleading. |
