# People, authority, power and communication

Used by vector modules 5, 6, 8 and 9. Public and professional information only (see the rules in SKILL.md).

## People analysis

```
CURRENT STATE: what they believe now; what they value; what is driving their behaviour
PROFILE:
  decision style:     analytical / emotional / social-proof / authority-led
  main motivation:    security / achievement / recognition / connection / autonomy
  main concern:       loss / rejection / failure / irrelevance / being controlled
WHAT WOULD CHANGE THEIR VIEW: which true fact or offer, if they saw it, would change their behaviour
```

Prediction: (1) main motivation, (2) main concern, (3) current belief about the situation, (4) who they look to, (5) path of least resistance. "They will [action] because it [serves/avoids/aligns]. To change the behaviour, change which input, with what true information?"

Legitimate influence techniques:
- Framing: the same facts with context that fits their goals. Never omit facts they would call material.
- Social proof: real examples of peers they respect doing the thing.
- Authority: make real credentials and results visible. Do not claim any you lack.
- Reciprocity: give first, genuinely, without a hidden ledger.
- Commitment: agree small steps that each stand on their own and say where they lead.
- Strategic silence: after a key statement, stop talking.

Pattern collection (professional and public only):

```
TEMPORAL:    work rhythms, communication patterns, decision timing, career timeline
SOCIAL:      professional associations, mentors, known counterparts, gaps in their network
BEHAVIOURAL: decision style, risk posture, response to pressure, record on commitments
CONTENT:     what they return to repeatedly; what they avoid (often revealing, but only an indicator)
```

Pre-meeting brief:

```
CURRENT STATE:      what is happening in their world now
LIKELY OBJECTIVES:  what they want from this interaction
SENSITIVE TOPICS:   what needs careful handling
WHAT WOULD INTEREST THEM in Shaun's offer:
PREDICTED BEHAVIOUR: how they open, likely objections, how they signal interest
APPROACH:           open, frame, navigate, close
SUCCESS SIGNAL:     an observable sign it went well
```

## Frame control

```
FRAME ASSESSMENT: what interpretive context governs this interaction, and who set it?
OPTIMAL FRAME:    what frame serves Shaun's objective?
ESTABLISHMENT:    how to set it from the start
```

Techniques: slow down and pause; ask questions; state conclusions instead of explaining unprompted; accept criticism calmly and move on.

Status signals:

```
USE:     unhurried speech, comfortable silence; setting the agenda; brief answers;
         saying directly what he wants; not fishing for approval
REMOVE:  hedging ("just a thought", "I might be wrong but"); credentials before the point;
         checking for approval after speaking; over-explaining; apologising for taking space
```

Hedging that reflects real uncertainty is honest and stays: say what is uncertain, once, then commit to a view.

## Pressure protocol

```
1. RECEIVE:     take the input without reacting; pause
2. ACKNOWLEDGE: "I hear you", without endorsing
3. ASSESS:      valid / partly valid / moved away from the issue
4. RESPOND:     valid: "You're right about X. Here's how I see it..."
                partly: "There's something in that. I'd push back on Y."
                off-issue: "I notice we've moved away from the issue. Let's return to it."
5. HOLD:        state the position; do not retreat just to please
RULE: update on new information, never on pressure alone.
```

## Power mapping

```
FORMAL POWER: who has official authority
REAL POWER:
  GATEKEEPERS:        control access and information flow
  INFLUENCERS:        whose opinion decision-makers trust
  VETO PLAYERS:       can block even a decided outcome
  SUPPORTERS:         can advocate for Shaun
  INFORMATION NODES:  know what is going on
PATHS:
  DIRECT:   feasibility / credibility / risk
  INDIRECT via [influencer]: how to earn their support / their motivation / timeline
  OPTIMAL:  best combination of feasibility, speed, probability
POWER CURRENCY: what powerful people here value most
  Shaun's currency: what he can offer in it
  Gap: where it is weak and how to build it
```

## Communications

```
AUDIENCE:   one primary audience, not everyone
CORE MESSAGE: the single most important takeaway
SUPPORTING (max 3): evidence, a second angle, an answer to the likely objection
ACTION:     what to think, feel or do
CHANNEL / TIMING
```

Difficult messages:
- Bad news: bottom line first; facts plainly; cause; what changes; what stays the same; next steps.
- Criticism: valid, acknowledge and correct; partly valid, acknowledge that part and correct the rest; invalid, one factual response, no escalation.
- Under pressure: position in one sentence; the single strongest reason; brief acknowledgement of the opposition; restate; stop.

Narrative: `CURRENT: what is believed / DESIRED: what should be believed / OPTIONS: reshape, reframe, redirect, replace / EXECUTION: how, where, by whom, when`. All through true information.

Discipline: never send when emotional (wait); one message, one audience; lead with the conclusion; silence is a message, choose it; consistency over years shapes reputation more than any single message.
