# Operations templates

Used by vector modules 1 to 4. Fill with Shaun's real figures; delete lines that do not apply.

## Commander's intent

```
PURPOSE:         why this is being done, and the larger goal it serves
END STATE:       the observable state of the world on success (not tasks completed)
KEY TASKS:       up to 3 essential actions (what, never how)
CONSTRAINTS:     hard limits; crossing one invalidates the mission
ACCEPTABLE RISK: what Shaun will trade for the end state
```

Test: could someone execute this correctly if they lost contact and had to decide alone?

## Mission orders (delegating outcomes)

```
TASK:        what must be accomplished
PURPOSE:     why it exists and what it serves
END STATE:   what done looks like, observable
STANDARDS:   minimum acceptable output
CONSTRAINTS: what must not be done
INITIATIVE:  where they can act without checking back
DEADLINE:
```

## Decision process

```
1. RECEIPT:    what is actually being asked? Restate the mission.
2. ANALYSIS:   know / don't know / must assume / constraints / limitations
3. COURSES OF ACTION: 2-3 distinct courses (not variations); each suitable, feasible, acceptable
4. WAR-GAME:   per course: success scenario, failure scenario, the other party's response
5. DECISION:   best balance of risk, feasibility and end-state achievement
6. EXECUTE AND ADAPT: intent survives; the plan adapts on first contact
```

## Branches and sequels

```
BRANCH 1: if [condition] then [action]
BRANCH 2: if [condition] then [action]
BRANCH 3 (catastrophic failure): [fallback]
SEQUEL A: after phase 1 success then [next operation]
SEQUEL B: after phase 1 partial success then [adjusted next]
```

## Campaign plan

Strategic end state: specific enough to know when it is reached, ambitious enough to be worth a campaign. Example shape: "Cerberus generates $X per month from Y subscribers and is recognised as a leading independent market intelligence service for serious CFD traders in Australia, by [date]."

```
LINES OF EFFORT (run concurrently):
LOE 1: [name]  purpose / key tasks / measure of progress
LOE 2: ...

PHASES (sequential, each with transition criteria):
0 SHAPING        pre-conditions
1 ENTRY          first meaningful milestone
2 CONSOLIDATION  build on gains
3 EXPLOITATION   accelerate momentum
4 TRANSITION     sustain the achieved end state

DECISION POINT n: [condition]  options: continue / adjust / abort  latest decision time: [date]
```

## One-page order

```
SITUATION: environment, opportunities, threats, own capabilities
MISSION:   Shaun will [action] to [purpose], resulting in [end state] by [date]
EXECUTION: intent, concept of operations, phases, lines of effort
SUSTAINMENT: resources, schedule, review cycle
COMMAND:   decision points, reporting, who authorises phase transitions
```

## Reconnaissance

```
TERRAIN:     operating environment, key players, written and unwritten rules; who succeeded here and how
THREAT:      who works against the objective; capability; likely actions; what they depend on
OPPORTUNITY: favourable conditions, timing advantages, available support
GAPS:        missing information; assumptions needing verification
```

SALUTE (rapid read of an actor): Size, Activity, Location, Unit or identity, Time observed, Equipment or capability.

Watch items: `WATCH 1: description / indicator / what a change means / how to monitor`.

Intelligence-to-action bridge:

```
WHAT IS NOW KNOWN:   ...
ASSESSMENT UPDATE:   how this changes the picture
PLAN IMPACT:         confirms / requires adjustment
REMAINING GAPS:      acceptable to proceed?
DECISION:            GO / NO-GO / ADJUST
```

## Logistics audit

```
TIME:         hours per week required; sustainable at that pace?
CAPITAL:      total cost over what period
ENERGY:       cognitive and physical load; sustainable?
DEPENDENCIES: external inputs required; what if each fails?
CONSUMPTION RATE: how fast resources are used
RESUPPLY PLAN:    how replenished; what triggers it
CRITICAL VULNERABILITY: which line, if cut, ends the operation
VERDICT: SUSTAINABLE / MARGINALLY SUSTAINABLE / UNSUSTAINABLE
```

Time accounting:

```
Available hours per week:    X
Committed (non-negotiable):  X   (uni, work, sleep, family)
Discretionary:               X minus committed
Allocated by line of effort: must total less than discretionary
Reserve:                     at least 20% of discretionary; this is operational reserve, not waste
```

Culminating point indicators: output quality declining despite more effort; poorer decisions; rest no longer restoring full capacity; rising error rate. Response: consolidate and resupply before resuming.

## Doctrine sequences

- Before an operation: reconnaissance, power mapping, people analysis, intent, campaign plan, logistics audit.
- Engagement: authority and frame, people analysis, negotiation, communications afterwards.
- Long campaign: campaign plan, strategic patience, logistics, continuous reconnaissance, branches and sequels.
