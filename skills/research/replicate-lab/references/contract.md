# Comparison contract

Version 1 JSON has `schema: 1`, nonempty `implementation`, `source` with a nonempty `locator`, `model`, `parameters`, `input_unit`, `output_unit`, `tolerance` (`absolute`, `relative`), and `rows`. Each row has a unique string `id`, numeric `x`, numeric `reported`, and `reported_unit`. `supplied-results` additionally requires each row's `reproduced` in `output_unit`; that mode records data rather than executing an independent method.

Supported reference kernels use converted canonical input and return canonical output: linear (`slope*x + intercept`), exponential-decay (`amplitude*exp(-rate*x)`), power-law (`amplitude*x**exponent`) and normal-pdf (`exp(-0.5*((x-mean)/sigma)**2)/(sigma*sqrt(2*pi))`). Parameters are canonical numeric coefficients, not unit-bearing strings. `output_unit` selects the output dimension; a reference-kernel result is already canonical and must not be multiplied by that display unit's conversion factor again. `supplied-results` is different: its explicit `reproduced` values are in the named `output_unit` and are converted. Normal PDF is only permitted with dimensionless inputs/outputs; dimensional densities need an independently derived implementation rather than a wrong automatic conversion. Parameters must include all fields, including zero-valued intercepts. Normalisation multiplies reference canonical output or supplied native output before reconciliation; affine-temperature normalisation needs particular care and an explicitly intended convention.

Units: `1`, `m`, `cm`, `mm`, `in`, `s`, `ms`, `min`, `h`, `kg`, `g`, `K`, `C`. Length/time/mass/temperature quantities convert through canonical m/s/kg/K. Unknown or incompatible units are errors. Celsius conversion is affine. Coefficient dimensions and modelling assumptions are declared by the analyst and are not proved by numeric conversion. Output normalisation `normalisation` is a finite positive multiplier, default 1; never infer it to make a mismatch disappear.

Convert both outputs to the same canonical dimension. Compare with `abs(reproduced-reported) <= absolute + relative*max(abs(reproduced),abs(reported))`; absolute tolerance is in canonical units. Report absolute difference, allowed tolerance and pass. Empty rows, duplicate IDs, booleans as numbers, non-finite values and overflow are errors. Maximum 10,000 rows, 4 MiB input, no network or execution of supplied code.

Fidelity ledger for real work: equation/algorithm locator; data version and SHA-256; reported convention; adopted convention; independent implementation file/hash; numerical precision/tolerance rationale; missing details; controls; changed-assumption experiment; comparison. Hashing identifies bytes, not provenance truth. This helper hashes the exact input and its own source and echoes source information without verifying it.
