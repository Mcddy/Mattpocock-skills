# Typed scene schema and render boundaries

JSON `schema:1`, `title`/`caption` strings <=500 characters, `source` string <=1000, `width`/`height` integers 32..512, `duration` and `fps` positive rational strings or finite numbers, `background` six-digit hex, `formats: [svg,png]` subset, `data` object of named numeric lists (max10000 total values), `scene` node list. Input <=2 MiB; node count <=200, group nesting <=8; frames <=120; pixel budget width*height*frames <=30 million and primitive raster work upper bound <=60 million pixel visits. No external resources.

Number fields accept a finite literal or exactly one binding object:
- `{data: name, index: integer, scale: number, offset: number}` resolves a numeric datum; scale/offset optional (1/0).
- `{keys: [[time,value],...], easing: linear|step|smooth}` uses strictly increasing nonnegative rational times. Clamp at endpoints; interpolate on the containing segment; `step` retains the left value. `smooth` is cubic smoothstep. Max1000 keyframes per field.
- `{function: sin|cos, frequency: number, phase: number, amplitude: number, offset: number}` evaluates offset+amplitude*fn(2*pi*frequency*t+phase). Frequency means cycles per second; phase radians. Function count and shape count are bounded, not arbitrary programs.

Nodes have unique string `id` and `type`. `rect`: x,y,width,height,fill. `circle`: cx,cy,r,fill. `line`: x1,y1,x2,y2,stroke,stroke_width. `text` SVG-only: x,y,text,size,fill. `group`: x,y,scale (positive uniform),children; defaults x/y0 scale1. All colour strings match #RRGGBB. Negative dimensions/radius/stroke width rejected; sizes <=10000 before/after transforms. Geometry can lie outside the viewport and is clipped in the raster. Unknown fields/types/binding keys rejected to expose typos. Text is escaped and capped at500 characters. XML-forbidden control characters/unpaired surrogates are rejected without stripping or replacing the source content; retain the original input and choose a valid representation explicitly.

Timing: frame count = ceil(duration*fps). Frame i occurs at exact rational i/fps, i=0..count-1; final time strictly below duration. Rational time is retained as numerator/denominator in the manifest and SVG title. Example29.97FPS uses `30000/1001`, not a roundeddecimal. This engine does not synthesize audio, align narration or guarantee motion readability at arbitrary FPS.

Every frame manifests flattened data-bound primitives and their computed numeric fields. PNG rasterisation writes RGB pixels with a deterministic stdlib zlib encoder. Rectangles/circles use pixel-centre inclusion; lines use distance-to-segment pixel-centre inclusion. SVG remains exact vector geometry; their pixel coverage is not claimed identical to a browser's antialiased rendering. PNG text is unsupported and rejected before creating output. No missing renderer silently produces blank bytes.

Output paths fixed by the compiler: scene.json, manifest.json, preview.html, frame-NNNN.svg/png. Fresh directory only. Manifest dependency hash covers exact input bytes and compiler bytes; frame hashes allow downstream content reuse but this CLI recompiles to a fresh directory and does not claim incremental cache invalidation. Preview imports only `{schema:1,index,theme}` with bounded index and warm/dark theme. It does not import code, arbitrary HTML or scene graphs. Reopen editable scene JSON by re-running compilation.
