# Geometry, units and invariants

JSON `schema:1`, `kind: organiser|polygon`, `unit: mm|cm|m|in`, optional `accent` as six-digit hex, maximum 2 MiB input. All geometry exports use millimetres. Numbers finite; bools rejected. Output directory must be new.

Organiser fields: `width`, `depth`, `height`, `wall`, `minimum_wall`, `minimum_slot_width`, `slots` integer 1..100. Positive dimensions. Width/depth >2*wall, height>wall, wall>=minimum_wall, slot clear width `(width-(slots+1)*wall)/slots >= minimum_slot_width`. Five outer/floor box components plus slots-1 dividers, disjoint interiors with shared contact boundaries. Overall x/y/z bounds [0,width], [0,depth], [0,height]. Floor spans width*depth*wall; front/back walls span full width and height above floor; sidewalls exclude front/back overlap; dividers span interior depth. Receipt volume is component sum, not a claim of boolean fusion.

Polygon fields: `points: [[x,y],...]` 3..200 vertices; `height` positive; optional `minimum_edge` nonnegative. Do not repeat the closing vertex. Coordinates share the declared unit. Reject adjacent duplicate points, non-adjacent segment intersections (including touch/collinearity), zero area and edges below minimum. The engine orients the polygon counterclockwise, then ear-clips it; triangle areas must sum to polygon area. It supports simple polygons only, no holes. Bounding-box dimensions and minimum edge do not prove every local wall thickness or manufacturing clearance; specify such constraints in a separate inspected design model.

Mesh exports: top/bottom triangulated caps and side quads, triangulated into oriented faces. Each component is checked for exactly two incident faces per undirected edge with opposite directed orientation, no zero-area triangle, and positive signed volume matching planar area*height within a numeric tolerance. Coordinates are finite. This establishes the bundled construction's closed component topology and volume, not all possible self-intersections of arbitrary 3D meshes or certification of fabrication quality.

SVG is an escaped inline polygon/line/text drawing with a viewBox and dimensions. Accent is validated; there are no external images, scripts or remote references. OBJ and JSON retain parameters, bounds and component names. Reopen by feeding `input.json` to the same CLI at a fresh output directory. Compare reconstructed metrics and hashes; metadata paths do not validate the user-supplied dimensions.
