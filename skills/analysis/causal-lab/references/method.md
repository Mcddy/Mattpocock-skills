# Identification and estimation contract

The graph includes observed and unobserved nodes explicitly. All directed edges are assumed causal. The validator first checks acyclicity. It rejects adjustment containing the treatment, outcome, any descendant of treatment or an unobserved node. It then removes outgoing treatment edges, takes the ancestors of treatment/outcome/controls, moralises that subgraph, removes controlled nodes and checks reachability. No remaining treatment-outcome path identifies the total effect under the declared backdoor assumptions. It does not discover hidden common causes or prove consistency/no interference.

The estimand is the sample-population average total effect for binary treatment: sum over discrete observed control strata of P(stratum) times [mean outcome(treatment=1,stratum) minus mean outcome(treatment=0,stratum)]. The weight uses all supplied rows in that stratum, not only treated rows. The input is not a longitudinal repeated-treatment model. Numeric category values are labels, not continuous regression adjustment.

Every target stratum requires both treatment states. With absent support, report stratum counts and supported contrasts; suppress the whole target ATE. Do not silently trim and relabel a different estimand. Singleton cells can produce a point contrast but no ordinary variance estimate. The script does not claim generalisation beyond the supplied design/population.

For explicit independent cluster identities, seeded cluster resampling repeats whole clusters and recomputes the estimator. At least four clusters are required; even then small-cluster percentile coverage can be poor. Resampled support failures above 10% suppress the interval; otherwise the displayed percentile interval is exploratory and conditional on valid replicates. Resampling checks neither causal assumptions nor hidden-confounding sensitivity. Report cluster counts, invalid replicate count and method alongside the interval.

Model changes belong in retained analysis branches: original graph, alternative graph, different target population and added measurements are distinct analyses. Sensitivity bounds require an explicitly declared perturbation model; a bootstrap width is not an unmeasured-confounding bound. A credible next experiment specifies randomisation unit, outcome definition/horizon, interference concerns and what evidence would falsify the operative assumption.
