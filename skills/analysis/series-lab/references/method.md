# Origin, release and calibration

The core supports a univariate fixed grid, explicit timezone and three deterministic baselines. ISO date-only observations denote end of that UTC day; datetime strings require offsets. `available_at` defaults to observation timestamp. Releases before the timestamp are refused in this core because it models observations, not advance covariates. Missing grid slots are explicit null-valued observations. Irregular timestamps, duplicate origins and excessive forecasts are refused.

At an origin, use rows with observation timestamp AND available_at no later than the origin. Naive uses the latest available observation. Seasonal-naive uses the matching phase from the most recent complete prior seasonal cycle; unavailable phases fall back to the latest observation with a visible reason. Drift extrapolates between first/latest available nonmissing observations over their actual grid-distance. Delayed last observations use the time gap to the requested target correctly. No target values participate in fitting their own forecast.

Backtest targets are scored only when nonmissing and released by evaluation_as_of. Each row records its score status and actual_available_at. Null is excluded from denominators; zero remains a measured target. MAE/RMSE/bias report n. Seasonal MASE denominator is computed once from values knowable at the first origin, never from later targets; absent or <=1e-12 denominator suppresses MASE. Percentage errors are deliberately absent because zeros/tiny denominators distort them.

Intervals are symmetric empirical absolute-residual intervals. For each method/horizon, only earlier forecasts with labels released by the current origin enter calibration. Minimum calibration defaults 5. The requested finite-sample rank is ceil((n+1)*(1-alpha)); if it exceeds n, no finite interval is claimed. Otherwise width is that ordered residual. This is prequential calibration, not guaranteed exchangeable split-conformal coverage for dependent/shifted data. Report calibration n and measured interval coverage with its own denominator. Insufficient n remains null.

Final method selection recomputes comparable completed backtest losses with labels available by final_origin. If no completed evidence exists, it chooses the explicitly labelled naive fallback. Final forecasts are always unscored even if future rows happen to be included in the historical input. Retrospective shift candidates compare adjacent six-observation median windows, rank absolute changes and carry no significance or mechanistic interpretation. They do not affect selection or predictions.

Auxiliary release checks and supplied training-boundary checks produce explicit violation records. The univariate core does not consume covariates; adding a candidate feature requires a separately reviewed model implementation with the same per-origin release checks. No neural model, exogenous-variable fit, automatic monitoring or statistical changepoint test is included.
