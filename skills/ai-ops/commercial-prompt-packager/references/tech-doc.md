# Technical documentation template

Tailor depth to tier: entry gets a simplified version, premium the full document.

```
# <Prompt name>: Technical Documentation

## Overview
1 to 2 sentences on what the prompt does.

## Recommended Model
<model> and why (verify the model is current).

## Deployment Context
System prompt, task prompt, API or chat interface.

## Required Inputs
What the user must provide.

## Output Description
Format, length, structure.

## Configuration Options
Variables, placeholders, settings the buyer can adjust.

## Usage Examples
2 to 3 example inputs with expected outputs (real runs, not invented).

## Known Limitations
Honest edge cases and failure modes.

## Version
v1.0, <date>
```
