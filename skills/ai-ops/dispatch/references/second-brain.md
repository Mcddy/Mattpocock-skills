# Second brain reference

## Layers

1. **Capture**: a frictionless inbox. Everything lands here first, no organising, under ten seconds.
2. **Process**: triage, not action. Five to ten minutes a day. Empty the inbox by routing or deleting.
3. **Organise (PARA)**: Projects (active work with a finish line), Areas (ongoing responsibilities such as trading, Cerberus, AI development), Resources (reference by topic), Archive (searchable, out of view).
4. **Review**: daily 5 minutes, weekly 30 minutes, monthly 1 hour.
5. **Express**: Cerberus, the prompt library, conversation as a thinking tool.

## Domain layouts

**Trading operations**: Active Positions (entry, size, stop, target, thesis, date); Trade History (outcomes, post-trade analysis, win and loss stats); Setup Library (setup name, criteria, entry rules, examples); Market Context (current macro thesis, key levels, catalyst calendar). Checklists: pre-trade, end-of-day debrief, weekly update.

**AI and prompt engineering**: Prompt Library (production versioned and tested, in development, commercial-ready); System Architecture (agent designs, pipeline blueprints); Test Cases (per-prompt suites, edge cases); Reference (techniques that work, failure modes and fixes); Revenue Tracking (which prompts earn).

**Cerberus**: Published Issues (archive and performance); In Progress (draft and research notes); Idea Bank; Source Library (trusted sources by category); Templates (issue, brief, analysis).

## Tool stack

| Function | Tool |
|---|---|
| Central knowledge base | Notion or Obsidian |
| Quick capture | Native notes app |
| Prompt storage | Notion or GitHub |
| Financial tracking | Notion and a spreadsheet |

Rule: fewer tools, better. Every tool is a system to maintain.
