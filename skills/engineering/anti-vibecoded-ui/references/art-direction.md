# Positive art direction and visible acceptance

For consequential design work, use a compact brief in existing notes: audience, decision, content object, constraints, intended character and viewing context. A trivial spacing fix does not need a design campaign.

## References that change decisions

Use a small set of relevant primary examples: a strong domain interface for task layout, original editorial/design-system work for typography, and an interaction example for state continuity. Name the mechanism worth learning. If useful, compare two genuinely different compositions with the same realistic content before choosing. Do not collect trend adjectives or copy identity, assets or trade dress. A reference may justify a principle without justifying its colours or layout here.

## Design decisions visible in the result

Choose the main object and reading order before cards or effects. Establish type roles through size, weight, leading and placement. Inspect actual line breaks, rags, fallback fonts and aligned baselines. Distinctiveness can come from subject imagery, hierarchy, density, useful comparison or expressive typography; no element is mandatory. Maintain familiar controls.

Ask: what deliberate choice can a reviewer point to, and how does it serve the task? A menu can keep prices and add buttons easy to scan while a chosen item's detail gets more space. A record repair can compare source, output and exceptions. A creator tool can give the canvas precedence. Do not use one showcase layout for all three.

## Portfolio capture and cover

Select a screenshot that demonstrates one useful decision or interaction. Capture after final UI changes using truthful content and an existing state. Do not retouch a screenshot to imply unimplemented behaviour. If a crop removes essential context, capture a different view. Give the image a single dominant reading priority; wrapper captions support it rather than compete with its headline.

Lead with a representative active state when interaction shows the value: populated basket, expanded case, completed draft or useful selection. Keep purposeful empty/recovery views as secondary demonstrations. Check every image edge for bisected text, controls or cards; distinguish a deliberate illustration bleed from an accidental broken-control crop. Match each claimed feature to visible and exercised evidence. A wordmark inside the application does not automatically duplicate an outer project title.

Judge at actual export dimensions, a plausible thumbnail and opened view. Record sizes. Essential offer text must survive the intended first view; details may require opening. Check native fields so the image does not repeat their title, role, skills and description. Covers orient to the service; cases demonstrate work. Keep accurate personal/fictional project context and relevant functionality limits clear. Do not automatically add AI disclosures or process badges. Follow the user's preference without claiming human-only authorship.

## Acceptance without false confidence

| Gate | Observable evidence | Failure response |
| --- | --- | --- |
| Task fit | Main object and primary action visible, realistic content | Change composition/content selection |
| Editorial hierarchy | Clear reading order, deliberate breaks, readable crop and text | Fix scale, capture or competing headings |
| Specificity | A project-dependent visible design decision and rationale | Reopen direction, not just accent colours |
| Truthfulness | Personal/synthetic status and relevant limits discoverable | Fix before external use |
| Behaviour | Main journey, difficult state and recovery exercised | Repair before functional claims |
| Human response | Show candidate at intended size; ask owner what work it communicates and what feels unresolved; record actual answer | Revise from feedback; silence is Not exercised |

An independent agent can critique and test behaviour, but is not a human buyer. A short comprehension exercise is qualitative feedback, not conversion evidence. Never average a blocker into a flattering score.
